Lecture 1: The Geometry of Linear Equations

Course: MIT 18.06 Linear Algebra — Lectures 1–34

Study topic: Lecture 1: The geometry of linear equations, including row and column pictures

Learning Objectives

  • Describe the row picture as plotting the points that satisfy each equation in the x–y plane.
  • Interpret a system Ax = b using the columns of A.
  • Explain a solution as both a point lying on the relevant lines and a linear combination of the columns producing b.

Explanation

A system of linear equations can be written as Ax = b. Here, A is the matrix of coefficients, x is the vector of unknowns, and b is the right-hand-side vector. In the row picture, examine one equation at a time. For two equations in two unknowns, each equation describes a line in the x–y plane. The solution is the point that lies on both lines. In the column picture, examine the columns of A. The equation Ax = b asks us to combine the columns of A in the amounts specified by the entries of x so that their linear combination equals b.

Key Points

  • The fundamental problem of linear algebra is solving a system of linear equations.
  • The row picture considers one row, or one equation, at a time.
  • For two equations and two unknowns, each equation gives a line in the x–y plane.
  • The solution is the point that satisfies both equations and therefore lies on both lines.
  • The column picture rewrites Ax = b as a linear combination of the columns of A equal to b.

Worked Example

Consider the system 2x − y = 0 and −x + 2y = 3. Row picture: the first equation gives a line containing the origin, since x = 0 and y = 0 satisfy 2x − y = 0. The solution is the point (1, 2), which lies on both lines: 2(1) − 2 = 0 and −1 + 2(2) = 3. Column picture: the coefficient matrix has columns [2, −1] and [−1, 2], while b = [0, 3]. The system asks for x and y so that x[2, −1] + y[−1, 2] = [0, 3]. Using x = 1 and y = 2 gives [2, −1] + 2[−1, 2] = [0, 3]. Thus the solution is the linear combination of the columns that produces b.
